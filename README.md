# Gameficação de Rotinas

Projeto da disciplina PRG04 - Programação Web (IFBA Campus Irecê), do professor Jonatas Bastos.

Site simples com tema de "gameficação de rotinas", feito em HTML, CSS e um pouco de JavaScript, usando o Bootstrap 5 para o layout responsivo.

## Páginas

- `index.html` — página inicial, com apresentação do projeto e cards das atividades.
- `login.html` — tela de login com validação de formulário (autenticação fictícia, sem back-end).
- `admin.html` — painel administrativo com uma tabela de usuários (dados fixos no código).
- `atividade-3.html`, `sandbox.html`, `paleta.html` — páginas de atividades e testes do curso.

## Tecnologias

- HTML5 semântico (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)
- CSS3 (mobile first, com Media Queries para tablet e desktop)
- Bootstrap 5 (grid, tipografia, cards, formulários, tabelas e badges)
- JavaScript puro (validação do formulário de login)

## Como abrir

Não precisa de instalação. Basta abrir o arquivo `infraestructure/pages/index.html` no navegador.

## Estrutura de pastas

```
infraestructure/
├── assets/
│   ├── css/      -> style.css
│   ├── js/       -> login.js
│   ├── image/
│   ├── audio/
│   └── favicon.ico
└── pages/        -> todas as páginas .html
```
